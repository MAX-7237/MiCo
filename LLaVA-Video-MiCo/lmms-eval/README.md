# Video evaluation engine

The retained adapter evaluates LLaVA-Video with MiCo. Supported task families are VideoMME, MVBench, LongVideoBench and MLVU. Prepare data using the corresponding task configurations under `lmms_eval/tasks`, then use the [MiCo launcher](../run_mico.py).

This engine is based on lmms-eval; its original [license](LICENSE) is preserved.
